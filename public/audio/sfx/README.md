# Sound effects

Not included. Add your own files with these names (or change the names in `scripts/sound.py`):

- `single-camera-click.mp3`: a short, dry camera click (presses, small UI taps)
- `camera-shutter-click.mp3`: a camera shutter (cards and thumbnails landing)
- `mouse-click.wav`: a real mouse click (the cursor pressing buttons)
- `reverse-crash.wav`: a reverse cymbal or riser (into the ending)

Whooshes, taps and thumps are synthesized in `scripts/sound.py`, so they need no files. Then run `npm run sound`.
